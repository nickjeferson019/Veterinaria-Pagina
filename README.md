## 📋 Sobre el proyecto
 
Sitio web informativo para una clínica veterinaria, con presentación de los
servicios, información de contacto y un acceso para usuarios registrados.
 
El objetivo fue construir una interfaz responsiva y navegable únicamente con
tecnologías del lado del cliente, sin frameworks ni dependencias externas.
 
---
 
## ✨ Características
 
- 🏠 **Página principal** con presentación de la clínica y sus servicios
- 🔐 **Acceso de usuarios** mediante formulario de inicio de sesión
- 📱 **Diseño responsivo** adaptable a móvil, tablet y escritorio
- 🧭 **Navegación entre secciones** con páginas internas enlazadas
- ⚡ **Interacciones dinámicas** implementadas en JavaScript puro
